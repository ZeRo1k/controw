# 📱 Web Controller Server

> **Turn any mobile device into a low-latency controller in seconds—no app installation required.**

Simply run the executable on your PC, scan the generated terminal QR code with your phone camera, and immediately start controlling your session over local Wi-Fi.

---

### ✨ Features
* **⚡ Instant Pairing:** Built-in TUI generates a QR code right in your terminal for one-tap mobile connection.
* **🌐 Web-Based Controller:** Runs in any standard mobile browser—no native apps, drivers, or software needed on the phone.
* **📊 Live Terminal UI:** Real-time dashboard showing player slots, connection latency, packet rates, and event logs.
* **⚡ Low Latency:** Optimized socket connections for responsive, real-time input handling.
* Must have vigem
